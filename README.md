# 🐾 TinyTalk: Animals

**TinyTalk: Animals** — це інтерактивний мобільний додаток для дітей віком 2–3 років, розроблений для першого знайомства з англійською мовою через вивчення назв тварин.

Проєкт створено в межах **Лабораторної роботи** з дисципліни розробки мобільних додатків.

---

## 🎯 Про ідею та індустрію

* **Обрана індустрія:** Дошкільна освіта.
* **Цільова аудиторія:** Малюки 2–3 років та їхні батьки.
* **Основна мета:** Забезпечити безпечне, просте та наочне середовище для засвоєння перших 10 англійських слів без зайвого текстового навантаження.

---

## ✨ Основні вимоги та функціонал

1. **Каталог з 10 тварин:** Вивчення назв (Cat, Dog, Cow, Duck, Lion, Elephant, Sheep, Pig, Bear, Monkey).
2. **Аудіосупровід:** Озвучка вимови англійською мовою та реалістичні звуки тварин при натисканні.
3. **Child-Friendly UI:** Великі інтерактивні картки, яскраві кольори та відсутність складних меню.
4. **Offline-First:** Повна автономна робота додатку без підключення до мережі Інтернет.
5. **Кросплатформеність:** Адаптивний інтерфейс для мобільних пристроїв та планшетів.
